Crypto Address Categorization System

Cryptocurrency is the de-facto currency for modern criminal activities, including money laundering, drug trafficking, and terror financing. Given the pseudo-anonymous nature of crypto, there is a critical need for a system to: Continuously collect cryptocurrency addresses from the internet (Surface/Deep Web). Associate these addresses with suspect entities/contextual PII. Categorize the addresses based on suspect activity. Provide an analytical front-end for querying the data. Our solution aims to be an autonomous system that builds an intelligence database to aid cybersecurity and financial monitoring efforts.
